Using the Printer in F-308

These instructions are for using the printer in F-308 during class time. You will not be able to print to this printer for personal use or for your other classes.

Step 1: Create a PDF

First, create a PDF of the document you want to print.

  • For most applications: go to File > Print > Print to PDF.
  • On MacOS: go to File > Print, then look for the PDF button at the bottom of the print dialog and save your file as a PDF.

Make sure to save the file somewhere you can find it.

Step 2: Submit the print job

Once the file is saved as a PDF, follow these steps:

  1. Go to the Macomb PaperCut website: papercut.macomb.edu.
  2. Log in with the print card number provided by your instructor.
    • For example, a username might be g123456 and the password would be the same, g123456.
  3. Select Web Print, then select Submit a Job.
  4. Select the following printer: s-app-001\SF308R1.
  5. Click the green button at the bottom labeled Print Options and Account Selection.
  6. Change the number of copies, if needed, then select Upload Documents.
  7. Upload the file from your computer and click Upload & Complete.

Print jobs will then be released by your instructor.
